# Linux System Administration to Cloud Project

## Secure Apache and Nginx Web Server Lab

This project documents my hands-on journey from Linux System Administration to Cloud Engineering.

The lab will include:

- Fedora Server virtual machines
- Apache HTTP Server
- Nginx comparison
- Network configuration and local name resolution
- SSH key-based authentication
- firewalld and SELinux
- Bash automation scripts
- systemd services and timers
- Backup, off-server copy, checksum verification, and restore testing
- Monitoring, logs, and troubleshooting
- Git and GitHub documentation
- AWS cloud mapping
